# Images d’entrée

Placez ici vos fichiers image (`.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`) pour le notebook `coco_inference_360.ipynb`.

Vous pouvez aussi définir `INPUT_PATH` dans le notebook vers un **fichier unique** ou un **autre dossier**.

Pour les panoramas **équirectangulaires** (souvent ratio 2:1), activez `USE_360_STRIPS` dans le notebook pour le découpage vertical avant détection DETR.
