Dessin vectoriel

Dessin libre : tracer à la souris. Ligne / Flèche : premier clic = départ, second = arrivée. Ligne par points : chaque clic place un point. Formes : premier clic = coin/centre, second = taille. Sélection : déplacer/redimensionner. Supprimer (bouton ou Delete). Dupliquer : copie décalée. Double-clic sur un texte pour éditer. Utilisable au doigt sur tablette.
